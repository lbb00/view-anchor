view-anchor: interactive 3D demo

Keep external surfaces (native views, canvases, iframes) aligned with DOM placeholders, and let a surface report its content size back to the page. The page below stays live while tilted: drag, scroll and click it directly.

Each surface follows its slot through createViewAnchor. Everything below happens on the page itself, tilted or flat:
  • Drag the vertical splitter. Both slots resize, so a ResizeObserver sees it. Surface B's items rewrap, and createSizeAnchor reports the new height back to the page.
  • Drag the header's lower edge. The slots move but keep their size, so no observer fires. Pressing a role="separator" (the default holdSelector) keeps the followGeometry frame loop open for the whole drag. Turn followGeometry off and try again.
  • Scroll the page body. followScroll re-measures on ancestor scrolls; the page clips each surface to the scroll viewport. Turn followScroll off and scroll again.
  • Click collapse. The page moves the slots itself, so it calls pulse() to re-measure on the next frames.
  • Click + / − on surface B. Its content changes height; the page resizes slot B. Slot A moves without resizing, so the page calls pulse() on A.
  • Click hide A. The slot gets display: none; treatZeroAreaAsHidden publishes { visible: false } instead of a 0×0 rect.
